# Etapa 10: componentes com JavaScript

Nova página, `trilha.html`, o detalhe da Trilha do Salto (o botão "Ver trilha" do primeiro cartão leva a ela):

- **Carousel** com três fotos, indicadores e controles com texto para leitores de tela.
- **Offcanvas**: o painel lateral "Dicas de segurança".
- **Modal** "Conte como foi", com o formulário do relato (ainda sem salvar: isso chega nos capítulos 20 e 23).
- **Breadcrumb** no topo, e os dados da trilha numa coluna ao lado no computador.

Todos dependem do `bootstrap.bundle.min.js`, no fim do `<body>`.
