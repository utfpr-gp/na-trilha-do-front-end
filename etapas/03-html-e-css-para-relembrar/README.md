# Etapa 03: estrutura semântica e CSS próprio

O cartão ganha uma página de verdade:

- `index.html`: cabeçalho, conteúdo principal e rodapé com as tags semânticas (`header`, `main`, `section`, `article`, `footer`) e os títulos em ordem (`h1` → `h2` → `h3`).
- `css/style.css`: as regras próprias do Trilheiro, carregadas **depois** do Bootstrap.

Para rodar: `npm install` e abra o `index.html` com o Live Server.
