# Etapa 02: o Trilheiro vira um projeto

O cartão do capítulo 1, agora como um projeto de verdade:

- `package.json`: a identidade do projeto, com o Bootstrap como dependência.
- `.gitignore`: diz ao Git para não guardar a pasta `node_modules/`.
- `index.html`: o cartão, com o CSS do Bootstrap vindo da `node_modules/`.

Para rodar:

```bash
npm install
```

Depois, abra o `index.html` com o Live Server do VS Code.
