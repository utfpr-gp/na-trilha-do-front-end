# Etapa 07: as trilhas em destaque no grid

A seção "Trilhas em destaque" ganha três cartões, organizados pelo grid do Bootstrap:

- `.container` no `<main>`, uma `.row g-4` e cada cartão numa coluna `.col-12 .col-sm-6 .col-lg-4`.
- 1 cartão por linha no celular, 2 a partir de 576 px, 3 a partir de 992 px.
- `.h-100` nos cartões, para os da mesma linha terem a mesma altura.
