# Etapa 15: tipografia fluida

- `scss/_functions.scss`: a função `fluid($min, $max, $de, $ate)`, que gera um `clamp()` com o tamanho mínimo, o máximo e a reta entre eles, e a função `rem($px)`.
- O título da faixa de destaque vai de 1,75rem (telas de até 360px) a 2,75rem (a partir de 1200px).
- Os títulos de seção (`.secao-titulo`) vão de 1,5rem a 2rem.
