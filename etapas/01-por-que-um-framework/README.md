# Etapa 01: o mesmo cartão, duas vezes

O cartão de uma trilha feito de dois jeitos, para comparar:

- [`css-puro/`](css-puro/): o HTML e um `style.css` escrito à mão.
- [`bootstrap/`](bootstrap/): o mesmo HTML com as classes do Bootstrap 5.3, que vem pelo CDN.

Abra cada `index.html` com o Live Server do VS Code (ou direto no navegador) e compare.
