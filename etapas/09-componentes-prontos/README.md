# Etapa 09: componentes prontos

O Trilheiro ganha os componentes do Bootstrap que o protótipo apontou:

- **Navbar** no cabeçalho (`navbar navbar-expand-md`, com `data-bs-theme="dark"`), com o menu "hambúrguer" no celular. O menu depende do JavaScript do Bootstrap, que entra no fim do `<body>` (`bootstrap.bundle.min.js`).
- **Card**, **badge** e **botões** (`btn-primary` e `btn-outline-secondary`).
- **Bootstrap Icons**, instalados pelo npm (`npm install bootstrap-icons`): bússola na marca, local, distância e duração nos cartões, e o coração do favorito.
- Um `<h1>` no começo do conteúdo, já que o nome do site foi para a navbar.
