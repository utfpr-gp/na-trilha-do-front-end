O protótipo do capítulo 5 apontou os componentes que viriam prontos do Bootstrap. Hoje eles chegam: o cabeçalho vira uma navbar, com a marca, os links das três telas e um menu "hambúrguer" no celular; os cartões ganham ícones (local, distância, duração) e um botão de favorito com um coração.

Você não escreve o CSS de nenhum deles. Você monta o HTML com as classes certas, na estrutura que a documentação do Bootstrap mostra, e entende o papel de cada peça. O resultado está em etapas/09-componentes-prontos.

Você não costura a sua mochila: compra uma pronta, testada, com alças, fivelas e bolsos que funcionam. Mas precisa saber montá-la: qual alça vai no ombro, qual fivela fecha a barrigueira. Montada errado, ela machuca.

Um componente do Bootstrap é esse equipamento de fábrica. A documentação é o manual: diz quais peças (elementos e classes) existem e onde cada uma encaixa.

Um componente é um conjunto de classes que trabalham juntas, numa estrutura de HTML esperada. Fora dessa estrutura, ele não funciona direito. Os quatro deste capítulo:

Card

.card é a moldura; .card-img-top, a imagem no topo com os cantos arredondados; .card-body, o miolo com respiro; .card-title e .card-text, o título e o texto. Você já usa desde o capítulo 1.

Botões e badges

O botão sempre leva .btn mais uma variante: .btn-primary (cheio, com a cor principal), .btn-outline-secondary (só o contorno). Tamanhos: .btn-sm e .btn-lg. O badge (.badge) é uma etiqueta pequena; a cor vem de .text-bg-warning, .text-bg-success e outras, que já escolhem um texto legível para cada fundo.

Navbar

A navbar tem mais peças, e cada uma tem um papel:

  • .navbar com .navbar-expand-md: a barra, que fica aberta a partir do md e recolhida abaixo dele;
  • data-bs-theme="dark": avisa que o fundo é escuro, para os links e o ícone ficarem claros;
  • .navbar-brand: a marca, à esquerda;
  • .navbar-toggler: o botão "hambúrguer", que só aparece no celular. Os atributos data-bs-toggle="collapse" e data-bs-target="#menu" dizem o que ele abre;
  • .collapse.navbar-collapse com id="menu": a parte que recolhe;
  • .navbar-nav, .nav-item e .nav-link: a lista de links; .active com aria-current="page" marca a página atual, para a vista e para o leitor de tela.

O botão "hambúrguer" precisa de JavaScript para abrir e fechar o menu. Por isso, neste capítulo, o JavaScript do Bootstrap entra na página. Os componentes que dependem dele são o assunto do capítulo 10.

Ícones

Os Bootstrap Icons são uma fonte de ícones: cada ícone é uma classe, como bi bi-geo-alt, num <i>. Ícones que só enfeitam levam aria-hidden="true", para o leitor de tela não anunciar nada. Um botão só com ícone precisa de um aria-label, como o "Favoritar" do coração, senão ele vira um botão sem nome.

Tire o <script> do bundle e teste no tamanho de celular: o botão "hambúrguer" aparece, mas não abre o menu, e nenhuma mensagem de erro aparece. O HTML e o CSS do componente estão lá; falta o comportamento. Agora tire o data-bs-theme="dark" da navbar: os links ficam escuros sobre o verde.

As causas mais comuns: o bootstrap.bundle.min.js não foi incluído (ou o caminho está errado, o que aparece como um 404 na aba Network); ou o data-bs-target="#menu" não bate com o id="menu" do bloco .collapse. Confira o caminho do script e se o alvo começa com # e tem exatamente o mesmo nome do id.

Por que o botão "hambúrguer" da navbar precisa do bootstrap.bundle.min.js?

O CSS está no bootstrap.min.css. O JavaScript cuida só do que muda com a interação.

A navbar aparece sem o JavaScript; só o menu recolhido não abre.

O que o data-bs-target="#menu" do botão precisa encontrar?

O # indica um id, e não uma classe.

O alvo é um elemento da própria página, identificado pelo id.

Um botão só com o ícone de coração precisa de quê para ser acessível?

O tamanho não dá nome ao botão. Quem usa leitor de tela precisa ouvir o que ele faz.

O leitor de tela não descreve o desenho de um ícone de fonte. Sem o aria-label, o botão fica sem nome.

Na navbar, para que serve o data-bs-theme="dark"?

A cor de fundo vem do seu CSS (o verde-mata). O atributo muda as cores do conteúdo para combinar com um fundo escuro.

No elemento da navbar, ele vale só para ela e o que está dentro dela.
