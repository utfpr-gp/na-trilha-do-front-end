Uma lanterna sem pilhas tem tudo no lugar: o corpo, a lâmpada, o botão. Você aperta, e nada acontece. Não há defeito à vista; só falta energia.

Um modal sem o JavaScript do Bootstrap é essa lanterna. O HTML e o CSS estão prontos, mas abrir, fechar, deslizar e prender o foco do teclado são comportamentos, e quem traz o comportamento é o arquivo de JavaScript.

Esses componentes funcionam sem você escrever JavaScript, graças aos atributos data-bs-*. Ao carregar, o script do Bootstrap procura esses atributos na página e liga cada botão ao seu alvo:

  • data-bs-toggle: o que o botão faz (modal, offcanvas, collapse);
  • data-bs-target="#id": em qual elemento;
  • data-bs-dismiss: o botão que fecha (o "×" e o "Cancelar");
  • data-bs-slide e data-bs-slide-to: os controles do carrossel.

Modal

Uma janela por cima da página, que escurece o fundo e prende o foco do teclado dentro dela até fechar. Use para uma tarefa curta que não merece uma página: deixar um relato, confirmar uma ação. Experimente:

Offcanvas

Um painel que desliza da lateral, bom para conteúdo de apoio que não precisa ficar sempre à vista: filtros, um menu, dicas. Funciona como o modal (escurece o fundo, fecha com Esc), mas encostado numa borda: offcanvas-end (direita), offcanvas-start (esquerda), offcanvas-bottom.

O seu código usou bootstrap.Modal, mas o bootstrap.bundle.min.js não foi carregado, ou foi carregado depois do seu script. A ordem no fim do <body> é: primeiro o Bootstrap, depois o seu arquivo.

O bootstrap.min.js não traz o Popper, uma biblioteca que posiciona menus suspensos (dropdowns) e dicas (tooltips). O bootstrap.bundle.min.js já vem com ele. Use o bundle, a menos que você carregue o Popper à parte.

Quando usar um offcanvas em vez de um modal?

Os dois têm usos diferentes: o modal para uma tarefa curta no centro, o offcanvas para apoio na lateral.

O offcanvas também precisa do JavaScript do Bootstrap.

No seu projeto, use pelo menos dois componentes com JavaScript onde eles fazem sentido: um modal para uma tarefa curta e um carrossel ou um offcanvas. Teste cada um só com o teclado (Tab, Enter e Esc).
