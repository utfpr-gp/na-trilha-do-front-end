Três ajustes deixam a página do Trilheiro mais acabada. O rodapé passa a ficar sempre no fim da tela, mesmo quando o conteúdo é curto. O título "Trilhas em destaque" ganha, na mesma linha e alinhado com ele, um link "Ver todas as trilhas", que some no celular. E os espaçamentos saem do CSS próprio e viram classes no HTML.

Tudo isso com as classes utilitárias do Bootstrap: cada uma faz uma coisa só, e você combina várias. O resultado está em etapas/08-utilitarios-do-bootstrap.

Um canivete tem a lâmina, a tesourinha, o abridor, a chave de fenda. Cada peça faz uma tarefa, e nenhuma tenta fazer tudo. No mato, você abre a que precisa, na hora.

As classes utilitárias são as peças: py-4 dá respiro em cima e embaixo, d-flex põe os filhos lado a lado, d-none esconde. Em vez de inventar uma classe nova e escrever o CSS dela, você abre a peça certa direto no HTML.

Espaçamento: margem e padding

As classes de espaçamento seguem um padrão: propriedade (m para margem, p para padding), lado (t em cima, b embaixo, s no início, e no fim, x nas laterais, y em cima e embaixo, ou nada para os quatro lados) e tamanho, de 0 a 5:

Assim, py-4 é padding de 1,5rem em cima e embaixo, e mb-0 tira a margem de baixo. Com os pontos de quebra do capítulo 7, dá para variar por tamanho: p-2 p-md-4. O mt-auto é especial: uma margem que ocupa todo o espaço livre, empurrando o elemento para o fim.

Flexbox em classes

d-flex transforma o elemento num contêiner flexível: os filhos ficam lado a lado. A partir daí:

  • justify-content-between, -center, -end: distribuem os filhos na direção principal;
  • align-items-center, -baseline: alinham na outra direção;
  • flex-column: empilha os filhos; gap-3: espaço entre eles; flex-grow-1: deixa um filho crescer e ocupar o que sobra.

O Flexbox por baixo dessas classes é o assunto do capítulo 11, em CSS puro.

Visibilidade e texto

d-none esconde; d-sm-inline mostra de novo a partir do sm. Juntas, d-none d-sm-inline querem dizer "escondido no celular, visível do sm para cima". Para texto: text-center, fw-bold, text-uppercase, small e text-body-secondary, a cor de texto de apoio.

O rodapé no fim da tela

Numa página com pouco conteúdo, o rodapé sobe e fica no meio da tela. A solução tem três partes: o <body> vira um contêiner flexível em coluna (d-flex flex-column) com pelo menos a altura da tela (min-vh-100), e o <main> cresce para ocupar o que sobra (flex-grow-1). O rodapé é empurrado para baixo. Outro jeito, com o mesmo efeito, é pôr mt-auto no rodapé no lugar do flex-grow-1 no main.

Apague os padding e use py-4 px-3 no cabeçalho, py-5 no conteúdo e py-3 px-3 no rodapé. O CSS próprio fica só com o que é identidade (as cores e as fontes dos tokens), e os espaços seguem a escala do Bootstrap.

O align-items-baseline alinha os dois pela linha de base do texto, o que fica melhor que centralizar quando os tamanhos são diferentes. O mb-0 no título tira a margem que o Bootstrap põe em todo h2, que desalinharia o par.

Nos dados de cada trilha, use small text-body-secondary: texto menor e na cor de apoio, para o nome da trilha continuar sendo o destaque.

Tire o min-vh-100 do <body>: numa tela alta, o rodapé volta a subir. Devolva, e tire o flex-grow-1 do <main>: o efeito é o mesmo, porque agora ninguém ocupa o espaço que sobra. As três classes trabalham juntas.

Todo utilitário do Bootstrap usa !important:

Por isso, uma regra sua como .site-header { padding: 2rem; } perde para o p-3, mesmo vindo depois. Não brigue com ele: troque a classe no HTML (p-4, p-5) ou tire o utilitário e cuide do espaço só no CSS. Misturar os dois no mesmo elemento é pedir confusão.

As três peças precisam estar no lugar certo: d-flex flex-column min-vh-100 no pai (o <body>) e flex-grow-1 num filho direto dele (o <main>). Se houver uma <div> envolvendo tudo, as classes do pai precisam ir para ela.

d-none sozinho esconde em todos os tamanhos. Para esconder só no celular, combine com a classe que mostra de novo a partir de um ponto de quebra: d-none d-sm-inline, d-none d-md-block. E o contrário, esconder só no computador: d-lg-none.
O que faz a classe py-4?

O p é de padding, e o 4 é um degrau da escala (1,5rem), e não pixels.

O y é o eixo vertical (em cima e embaixo). As laterais seriam px.

Como esconder um elemento no celular e mostrá-lo a partir do md?

d-md-none faz o contrário: esconde a partir do md.

d-none sozinho esconde em todos os tamanhos.

Para o rodapé ficar no fim da tela, quais classes vão no <body>?

fixed-bottom prende o elemento na tela, por cima do conteúdo, mesmo ao rolar. Não é o mesmo que empurrar o rodapé para o fim.

Uma margem fixa não acompanha a altura da tela.

Sua regra .titulo { margin-bottom: 2rem; } não funciona num elemento com mb-0. Por quê?

Mesmo com o seu CSS depois, o !important do utilitário vence. Troque a classe ou tire o utilitário.

Margem funciona em títulos. O problema é o !important do utilitário.
