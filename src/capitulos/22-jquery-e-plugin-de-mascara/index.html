No cadastro do capítulo 20, quem digita o telefone do guia precisa acertar os parênteses, o espaço e o hífen, senão leva um "Use o formato (00) 00000-0000". Hoje o formulário passa a ajudar: o CEP e o telefone ganham máscaras. A pessoa digita só os números, e o hífen e os parênteses aparecem sozinhos, no lugar certo; letras nem entram.

Para isso, o Trilheiro usa o jQuery, a biblioteca que dominou o front-end por mais de uma década, e um plugin dele, o jQuery Mask Plugin, os dois carregados por um CDN. Você vai entender o que o jQuery faz, por que ele ainda aparece em tanto projeto, e quando o JavaScript de hoje já basta. O resultado está em etapas/22-jquery-e-plugin-de-mascara.

Antigamente, todo trilheiro levava um canivete suíço: abria lata, cortava corda, apertava parafuso, coisas que as ferramentas da época faziam mal. Hoje as mochilas vêm com bolsos e fivelas melhores, e o canivete ficou menos necessário. Mas a loja ainda vende acessórios que só encaixam nele.

O jQuery é o canivete: resolvia o DOM e os eventos quando cada navegador fazia de um jeito. Os navegadores melhoraram, e o querySelector e o fetch fazem quase tudo o que ele fazia. Mas existem muitos plugins prontos, como o de máscara, que só funcionam com ele.

jQuery e o JavaScript de hoje, lado a lado

Quando o jQuery nasceu, em 2006, a coluna da direita não existia, ou funcionava diferente em cada navegador. Hoje existe, e por isso projetos novos raramente adotam o jQuery. Mas você vai encontrá-lo em sistemas que já existem, em temas prontos e em plugins, e precisa saber lê-lo.

O plugin de máscara

Um plugin acrescenta métodos ao jQuery. O jQuery Mask Plugin acrescenta o .mask(), que recebe o formato: 0 é um dígito, e o resto (hífen, parênteses, espaço) entra sozinho. Experimente:

O valor do campo fica com a máscara (85010-260), que é o formato que a validação e o banco de dados esperam (RN04). Para os dígitos limpos, o plugin oferece o .cleanVal().

Pelo CDN, e na ordem certa

O jQuery e o plugin vêm de um CDN, com a versão fixa no endereço, como manda o architecture.md. A ordem importa: primeiro o jQuery, depois o plugin (que se pendura nele), e por último o seu código, que usa os dois.

O trail-form.js é um módulo, e mesmo assim enxerga o $: o jQuery, carregado por um <script> comum, fica disponível para a página inteira. E os módulos só rodam depois que a página foi lida, então o jQuery já está lá.

Pelo Live Server, abra o cadastro e digite 85010260 no CEP: aparece 85010-260. Digite 42999991234 no telefone: (42) 99999-1234. Tente uma letra: ela não entra. As mensagens do capítulo 20 continuam funcionando: um CEP pela metade ainda mostra "Use o formato 00000-000".

No console, confira a versão: $.fn.jquery responde '4.0.0'.

Troque a ordem dos dois <script> do CDN, com o plugin antes do jQuery, e recarregue: o console mostra o erro do plugin, as máscaras somem e, pior, o trail-form.js para na linha da máscara, e nenhuma validação funciona. Um erro num script derruba o que vem depois dele. Desfaça.

O plugin tenta se pendurar no jQuery, que ainda não existe. Logo depois vem um Uncaught ReferenceError: $ is not defined. A ordem é sempre: biblioteca, plugins, o seu código.

O jQuery está lá, mas o .mask() não: o <script> do plugin falta, ou o endereço está errado (confira a aba Network do DevTools: um 404 no plugin explica tudo).

O jQuery 4 removeu funções que o JavaScript já tinha, como o $.trim, o $.isArray e o $.now. Muito exemplo na internet é da época do jQuery 1 ou 3. Use o equivalente do JavaScript, e consulte o guia de atualização (link em "Para ir além").

O $('#cep') não é o elemento: é um objeto do jQuery que embrulha o elemento. Use os métodos do jQuery, ou desembrulhe com [0].

O jQuery tem uma versão "slim", menor, sem as funções de AJAX (.load(), $.ajax, $.getJSON) e de animação. Se um exemplo usa essas funções, carregue a versão completa, jquery.min.js.

O .val() é do jQuery: a lista do querySelectorAll não tem esse método.

Na máscara '(00) 00000-0000', o que significa o 0?

No plugin, o 0 é um lugar para um dígito, qualquer um de 0 a 9.

Só dígitos: é por isso que as letras não entram.

Em que ordem os scripts precisam vir?

O seu código usa o $ e o .mask(): os dois precisam existir antes.

Os scripts comuns rodam na ordem em que aparecem. O plugin precisa do jQuery já carregado.

Por que um projeto novo raramente começa com jQuery hoje?

Funciona muito bem: a versão 4 é recente. Ele só ficou menos necessário.

CDN é comum e o Trilheiro usa. A razão é que querySelector, classList e fetch cobrem o que o jQuery resolvia.

No seu projeto, use o jQuery e um plugin dele (o de máscara ou outro que faça sentido no seu tema), carregados pelo CDN com a versão fixa.
