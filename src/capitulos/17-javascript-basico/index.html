O Trilheiro ganha o seu primeiro arquivo de JavaScript, o js/app.js. Ele ainda não mexe na página: por enquanto, conversa com você pelo console do navegador. Dá bom dia (ou boa tarde, conforme a hora), mostra o resumo de cada trilha, com a duração escrita do jeito que as pessoas falam ("2h30", e não "150 minutos") e o ritmo em minutos por quilômetro, e três segundos depois manda uma dica.

Por trás disso estão as peças que todo o resto do livro usa: variáveis, tipos, funções, decisões com if, textos montados com template strings e um temporizador. O resultado está em etapas/17-javascript-basico.

Um guia experiente anota no caderno umas fórmulas que usa toda hora: "para saber a duração, divido a distância pelo ritmo do grupo". Ele não refaz o raciocínio a cada trilha; consulta a fórmula, troca os números e pronto.

Uma função é uma fórmula do caderno: tem um nome (formatDuration), recebe os números da vez (150) e devolve o resultado ("2h30"). As variáveis são os campos onde você anota os números.

Onde o JavaScript mora

Num arquivo .js, ligado ao HTML por um <script> no fim do <body>, depois do Bootstrap. No fim, porque assim o HTML já está todo carregado quando o script roda. O console.log() escreve no console do DevTools (F12 → Console): é o jeito mais simples de ver o que o seu código está fazendo.

Variáveis e tipos

Use const por padrão, e let só para o que vai mudar. O antigo var ainda funciona, mas tem regras confusas: deixe-o de lado.

O código usa duration, mas nada com esse nome foi criado (talvez o nome certo seja minutes, ou há um erro de digitação, ou a variável foi criada dentro de outra função). O console mostra o arquivo e a linha ao lado da mensagem: clique neles para ir direto ao erro.

Uma variável criada com const não pode receber outro valor. Se ela precisa mudar (como um contador), crie com let.

Dois let name (ou const) no mesmo bloco. Erros de sintaxe impedem o arquivo inteiro de rodar: nenhuma linha do app.js funciona até você corrigir. Para trocar o valor, escreva só name = 'Mirante';, sem o let.

Um dos valores era texto: '4' + 5 dá '45', porque com texto o + junta. Isso acontece muito com valores que vêm de campos de formulário, que são sempre texto. Converta antes de somar: Number('4') + 5.
Quando usar let em vez de const?

Os dois são modernos. Use const por padrão e let só quando o valor muda.

O tipo não importa: a diferença é se a variável pode ou não receber outro valor.

O que formatDuration(65) devolve?

65 minutos têm 1 hora inteira: a função só usa "min" quando as horas são zero.

O padStart(2, '0') completa os minutos com um zero à esquerda: 5 vira "05".

Qual é o resultado de `${'Salto'}: ${4.5} km`?

Com crases, o ${…} é trocado pelo valor. Com aspas comuns, ele apareceria como texto.

O JavaScript escreve números com ponto. A vírgula só com toLocaleString('pt-BR').

Qual a diferença entre setTimeout e setInterval?

Um roda uma vez; o outro repete até ser parado com clearInterval.

Os dois usam milissegundos: 3000 é 3 segundos.
